# Классификатор инцидентов

Сайт для подбора группы тем и темы по классификатору инцидентов:
https://markin1433.github.io/Klassiki/

Что есть на сайте:

- **26 групп и 359 тем** с подгруппами и вводными описаниями групп;
- для каждой темы — «Тема должна содержать», «Не путать с темами» (кликабельные ссылки на темы)
  и сноски-пояснения из свода;
- поиск по названиям, описаниям и спискам «Не путать» — понимает слова из обращения
  в любой форме («яма во дворе», «отключили свет»), подсвечивает совпадения;
- копирование в формате `Группа тем/тема - "ГРУППА" / "ТЕМА"` (официальные названия), группы или темы отдельно;
- **примечания коллег** к темам: оставить, изменить или удалить может любой, кто открыл сайт;
  все примечания — в отдельном разделе «Примечания» (там же выгрузка в Excel), они же учитываются в поиске;
- избранное (хранится в браузере), ссылки на конкретную тему, тёмная тема, мобильная версия.

Клавиши: `/` — к поиску, `↑` `↓` — выбор результата, `Enter` — открыть, `Esc` — очистить.

## Устройство

Статический сайт без сборки — GitHub Pages отдаёт файлы как есть.

| Файл | Назначение |
|---|---|
| `index.html`, `style.css`, `app.js` | интерфейс |
| `data.js` | данные классификатора (генерируются, вручную не править) |
| `config.js` | адрес хранилища примечаний |
| `xlsx.js` | выгрузка примечаний в файл Excel (без внешних библиотек) |
| `tools/notes-apps-script.gs` | код хранилища примечаний для Google Таблицы |
| `tools/build_data.py` | сборка `data.js` из PDF «Свод документации по Классификатору» |

Сайт открывается и локально — двойным кликом по `index.html`.

## Обновление данных из нового PDF

PDF со сводом **в репозиторий не загружается** (`*.pdf` в `.gitignore`) — он нужен только локально.

```bash
python3 -m pip install pymupdf
python3 tools/build_data.py "/путь/к/Свод_документации.pdf"
```

Скрипт:

- пропускает страницы 1–4 (обложка, оглавление, регламент и формат внесения изменений) и скриншоты-примеры;
- отбрасывает «невидимый» текст, который остался в PDF под плашками и белым по белому;
- склеивает переносы между колонками и страницами, распознаёт сноски и выделения;
- сопоставляет пункты «Не путать с темами» с темами (в своде они часто записаны неточно —
  ручные соответствия в `ALIASES` внутри скрипта);
- пишет `data.js` и обновляет метку версии в `index.html`, чтобы браузеры не показывали старые данные.

Подробный отчёт о спорных местах: `python3 tools/build_data.py <pdf> -v`.

## Примечания: Google Таблица

Примечания хранятся в Google Таблице владельца сайта — сайт обращается к ней через
небольшой скрипт (Google Apps Script). Сама таблица остаётся закрытой: коллеги работают
с примечаниями только через сайт.

Подключение (один раз):

1. Создайте Google Таблицу, откройте **Расширения → Apps Script**.
2. Замените код в редакторе содержимым `tools/notes-apps-script.gs`, сохраните.
3. **Начать развертывание → Новое развертывание**, тип **Веб-приложение**:
   «Запуск от имени» — **Я**, «У кого есть доступ» — **Все**. Подтвердите доступ к таблице.
4. Скопируйте URL веб-приложения (заканчивается на `/exec`) в `config.js` → `notesUrl`.

Удалённые примечания не стираются: в таблице у них стоит отметка в колонке `deleted` —
снимите её, чтобы вернуть. Если код скрипта поменяется, обновите его в редакторе и сделайте
**Развертывание → Управление развертываниями → Изменить → Новая версия** (адрес не изменится).
